# num-methods-solver
This project is a Java application that implements various numerical methods commonly used in engineering and mathematics. It includes both computational logic and a GUI for user interaction.

Methods Included:
- Bisection Method
- False Position Method
- Newton–Raphson Method
- Secant Method
- Fixed Point Iteration
- Cramer’s Rule
- Matrix Multiplication

# Project Structure
- [BisectionMethod.java:](nummethods/BisectionMethod.java) Implements the Bisection numerical method
- [CramersRule.java:](nummethods/CramersRule.java) Solves systems of linear equations using Cramer’s Rule
- [FalsePosition.java:](nummethods/FalsePosition.java) Implements the False Position method
- [FixedPoint.java:](nummethods/FixedPoint.java) Implements the Fixed Point Iteration method
- [NewtonRaphson.java:](nummethods/NewtonRaphson.java) Implements the Newton–Raphson method
- [Secant.java](nummethods/Secant.java) Implements the Secant method
- [MatrixMulti.java:](nummethods/MatrixMulti.java) Performs matrix multiplication operations
- [Gui.java:](nummethods/Gui.java) Main graphical user interface of the program
- [Gui2.java:](nummethods/Gui2.java) Extended GUI implementation
- [assets:](nummethods/assets) Includes the background image and font file used in the GUI

# How to Run
1. Clone or download this repository
2. Open the project in NetBeans (or any Java IDE)
3. Locate the src/nummethods package
4. Run either Gui.java or Gui2.java
5. Choose a numerical method, input the required values, and click Solve
